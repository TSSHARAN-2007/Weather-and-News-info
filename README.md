# 🌦️ News & Weather CLI App

A simple Python command-line application that lets users fetch **real-time weather data** and **top news headlines** using APIs.  
This project is part of my API learning journey, combining two different APIs into one interactive program.

---

## 🚀 Features
- Get **current weather** for any city using [OpenWeatherMap API](https://openweathermap.org/api).
- Fetch **top headlines** from India using [GNews API](https://gnews.io).
- Interactive CLI: choose between `news` or `weather`.
- Error handling for invalid inputs and API issues.
- Concise terminal output for easy readability.
